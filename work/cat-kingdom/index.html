Cat Kingdom

A 2D platformer where you switch between four cats to get through each level.

Play on itch.io ↗

About the game

I made it with a teammate for our game development midterm at DIS. There are three levels with a story intro and a final scene.

How it plays

You can swap cats at any point in a level. Each one has a single move. One rolls, one attacks, one double jumps and one flies.

Making it

We wrote it in C# in Unity. The art comes from third party sprite packs. In 2026 I rebuilt it for WebGL so it plays in the browser.
