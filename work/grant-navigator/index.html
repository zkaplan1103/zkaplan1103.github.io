Grant Navigator

Matches a nonprofit to grants and drafts the application text, with a check that blocks false claims.

GitHub ↗

The problem

Nonprofits find funding by digging through grants.gov, foundation sites and spreadsheets. It's slow. One false eligibility claim can get an organization barred. I started this after the EPA cancelled Solar for All in August 2025 and solar nonprofits had to replace that money quickly.

How it works

01Profile

The nonprofit describes itself and what it needs money for.

02Search

A live grants.gov search runs next to a hand-vetted list of foundation and state programs.

03Match

A Sonnet agent scores how well each grant fits and explains why.

04Draft

Sonnet writes application boilerplate for the strong matches.

05Verify

Opus checks every claim in the draft. Anything unsupported goes back for a rewrite or gets flagged for a person.

Verify benchmark

100%precision
100%recall
31test cases

Choices I made

  • No frameworkThe agent loop is written by hand on the Anthropic SDK.
  • Search is a toolOnly the steps that need judgment are agents.
  • Best model verifiesA cheaper model let made up claims through.
  • Vetted sourcesWhich sites to trust is decided ahead of time in a config file.

Limits

The hand-vetted sources only cover solar and clean energy for now. Any other focus still gets the full federal results.
