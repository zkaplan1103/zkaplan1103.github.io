Grant Navigator

Grant matches for nonprofits, with a check that blocks made up claims.

GitHub ↗

The problem

Nonprofits chase funding across grants.gov, foundation sites and spreadsheets. It is slow work. One false eligibility claim can get an organization barred. The project started after the EPA cancelled Solar for All in August 2025 and solar nonprofits had to replace that money fast.

How it works

01Profile

A nonprofit enters its funding focus and details.

02Discover

Live grants.gov search runs alongside a vetted list of foundation and state sources.

03Match

A Sonnet agent scores fit and ranks every result with a cited reason.

04Verify

A drafter writes application text. An Opus verify agent sends back anything unsupported. Holdouts go to a person.

Results

100%precision
100%recall
31benchmark cases
3agents, one bounded loop

Details

Discovery is a tool, not an agent. Source trust is a config list vetted ahead of time. The agent loop is written by hand on the Anthropic SDK with no framework.

The verify step runs on the strongest model on purpose. A cheap model waves hallucinations through.

The curated sources only cover solar and clean energy for now. Any other focus still gets full federal results.
