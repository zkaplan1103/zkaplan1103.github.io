Terrapin Rewards

A loyalty platform I built for a group of local businesses.

Live site ↗

The job

I led full stack development at Terrapin Rewards from January to November 2025. The goal was one loyalty system that several local businesses could share. Customers check in with a QR code and earn points toward rewards each business sets.

What I built

  • Shared platformOne React and Supabase app that serves every business.
  • Data isolationPostgreSQL row-level security so each business only sees its own customers.
  • AnalyticsReal time dashboards on the Square API for engagement and retention.
  • Custom featuresBuilt from requests that came out of regular meetings with the owners.

Notes

This was client work, so the code is private. The live site is public.

Built with

  • React 19
  • TypeScript
  • Supabase
  • PostgreSQL
  • Square API
