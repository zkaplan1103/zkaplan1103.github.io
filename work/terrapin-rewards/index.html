Terrapin Rewards

One loyalty platform for a group of local businesses.

Live site ↗

The problem

Local businesses wanted a loyalty program without each one running its own system. Customers wanted one place to check in and collect points.

How it works

01Check in

Customers scan a QR code at the counter.

02Earn

Points build toward rewards that each business sets.

03Isolate

Row level security in PostgreSQL means each business only sees its own data.

04Track

Real time dashboards on the Square API show engagement and retention.

Results

11months
1platform, many businesses
RLSper business data isolation
