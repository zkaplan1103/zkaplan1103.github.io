mcp-verify

A hallucination detector with a real benchmark behind it.

GitHub ↗

The problem

AI drafts sound confident even when they are wrong. Checking every claim by hand is slow. Most detectors never prove they work. I wanted one that shows its numbers.

How it works

01Input

You give it a source of truth and a draft to check.

02Check

Each claim in the draft is checked against the source.

03Report

Unsupported claims come back as JSON with a reason, the source fact checked, a category and a severity.

04Confirm

Reliability mode runs the check several times. It keeps the claims a majority agree on and moves unstable ones to an uncertain list.

Results

97.9%precision
99.1%recall
106labeled cases
4domains plus a red team set

Details

It runs as a Python library or as an MCP server with one tool. As a server it can borrow the host's model through MCP sampling. That means no API key and no extra cost.

The eval suite travels with the detector. It has a 15 type hallucination taxonomy and an adversarial red team set. It runs in CI so accuracy can't slip before a release.

Every remaining failure is reviewed and written up in the benchmark doc. Next I want more domains and a bigger red team set.
