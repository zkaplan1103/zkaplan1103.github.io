mcp-verify

Checks an AI draft against a source and flags every claim the source doesn't support.

GitHub ↗

The problem

Language models write confident text that is sometimes wrong. If that text goes to a customer, someone has to check every claim. I wanted a checker I could trust, so I built one and measured how often it's right.

What it does

You pass in a source of truth and a draft. It returns each claim the source doesn't back up. Every flag comes with a reason, the fact it checked, a category and a severity.

It works as a Python library or as an MCP server with one tool. As a server it can use the host's own model through MCP sampling, so it runs without an API key. A reliability mode runs the check several times and only keeps the claims most runs agree on.

Results

97.9%precision
99.1%recall
98.5%F1
106labeled cases

The benchmark

  • 106 casesLabeled drafts across 4 domains.
  • Red team setAdversarial cases written to slip past the checker.
  • 15 typesA taxonomy of the ways a draft can be wrong.
  • 3 runsScores are averaged over three runs with 95% confidence intervals.
  • CI gateThe suite runs on every change so accuracy can't quietly drop.

Notes

Every miss that's left is written up in the benchmark doc along with why it happened.
