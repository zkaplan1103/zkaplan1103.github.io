BizBrief

Customer reviews in. A ranked weekly action brief out.

Live demo ↗GitHub ↗

The problem

Small business owners get a flood of reviews and no time to read them. They need to know what to fix this week. They also need the reviews that prove it.

How it works

01Ingest

Reviews are grouped by business and by week.

02Route

A complexity score sends each batch to the cheapest Claude model that can handle it. Haiku, Sonnet or Opus.

03Classify

Claude tags recurring themes and sentiment and keeps the review evidence for each one.

04Brief

The top issues are ranked by impact. Each one gets a recommended action and a draft email.

Results

72%lower projected spend
36xcheaper than Opus on the eval batch
14red team findings, 12 fixed
3Lambda stages

Details

Routing and prompt caching bring the projected cost from about 99 cents to 28 cents per thousand reviews.

The serverless version is built with AWS SAM. Dropping a file in S3 fires an ingest, analyze and brief Lambda chain that writes to DynamoDB. Failed runs land in an SQS dead letter queue with an alarm. The API key lives in Secrets Manager. Every role only gets the actions its handler calls.

The AWS stack is deployable but not deployed, since running it costs real money. The live demo uses simulated data for four fictional businesses.
