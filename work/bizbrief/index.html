BizBrief

Turns a week of customer reviews into a short list of what to fix.

Live demo ↗GitHub ↗

The problem

Small business owners get more reviews than they can read. The useful part is usually a few repeated complaints. I wanted something that pulls those out every week and backs each one with the reviews that prove it.

How it works

01Ingest

Reviews come in grouped by business and week.

02Route

Each batch is scored on length, star spread and vocabulary. Then it goes to the cheapest model that can handle it.

03Analyze

Claude tags themes and sentiment and keeps the reviews behind each one.

04Brief

The top issues are ranked by impact. Each gets a recommended action and a draft reply.

AWS version

I also built an event-driven version on AWS with SAM. Uploading a file to S3 starts a chain of Lambda functions that ingest, analyze and write the brief to DynamoDB. Failed runs go to an SQS dead letter queue with an alarm.

It reuses the same routing, caching and retry code as the local version. It passes validation but isn't deployed, since running it costs money. The live demo uses simulated data for four made up businesses.

Security

I red-teamed the API before calling it done. That turned up 14 findings. I fixed 12, and the other 2 were low risk. The fixes included per-IP rate limits, API key auth with lockouts, path checks and a cap on request size.
