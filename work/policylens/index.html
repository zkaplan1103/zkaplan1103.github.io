PolicyLens

Answers questions about a privacy policy and cites the exact clause it used.

GitHub ↗

The problem

Nobody reads privacy policies. They're long and written by lawyers. I wanted to ask a normal question, like whether an app shares my data with advertisers, and get a short answer I could check.

How it works

01Ingest

115 real policies from the OPP-115 corpus are split into 2,393 labeled clauses.

02Retrieve

The question is matched against that policy with vector and keyword search, then reranked. The top five clauses come back.

03Answer

Claude answers from those five clauses only and cites each one.

When it says no

The hardest part was getting it to admit when a policy doesn't cover something. There are two checks. If no clause scores high enough, it stops before calling the model. If the model reads the clauses and they don't support an answer, it says so instead of guessing.

Evaluation

167golden questions
30of them unanswerable on purpose
0.80faithfulness floor in CI
157unit tests

Production

The production version runs on Supabase pgvector behind API Gateway and Lambda, set up with Terraform. CI runs the eval and blocks a change if faithfulness or abstention accuracy drops below its floor.
