PolicyLens

Ask a privacy policy a question. Get the clause that answers it.

GitHub ↗

The problem

Privacy policies are long and written by lawyers. People want a straight answer to a normal question. Does this app share my data with advertisers?

How it works

01Ingest

115 real policies from the OPP-115 corpus are split into 2,393 labeled clauses.

02Retrieve

Hybrid vector and full text search plus a reranker return the top five clauses.

03Answer

Claude answers from those clauses only and cites each one it used.

04Abstain

If no clause clears the confidence floor, the app says the policy doesn't cover it.

Results

Details

Every citation traces back to a real clause ID and real text from the policy. The model is told not to use outside knowledge.

The production path runs on Supabase pgvector behind API Gateway and Lambda, set up with Terraform. CI runs faithfulness and abstention checks and blocks a change if either drops below its threshold.

Two separate abstention paths keep it honest. One stops weak matches before the model runs. The other lets the model refuse when the clauses don't support an answer.
