Air Labs GTM Pipeline

Cleans, enriches and scores a messy list of inbound leads for Salesforce.

GitHub ↗

The brief

This started as a take-home for a GTM engineering role at Air. The task was to turn a messy CSV of inbound leads into something sales could use. I built the pipeline and wrote a case study on how it would run in production.

The pipeline

01Ingest

Parse the CSV and check every row against a Zod schema.

02Normalize

Clean emails, phones, dates and company names. Drop bad emails and remove duplicates.

03Enrich

Look up each company through a mock data API with retries and a cache.

04Score

26 rules in a JSON file give each lead a score and a hot, warm or cold tier.

05Output

Write a Salesforce Bulk API payload and a separate list for human review.

Scoring rules live in JSON so sales ops can change them without touching code. Six checks run at the end and stop the job if any lead goes missing.
